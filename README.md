# AI Trader

A cloud-hosted trading bot project using Alpaca.

## Current stage

This starter version only verifies the Alpaca account connection. It does **not** place orders.

## Required Vercel environment variables

- `ALPACA_API_KEY`
- `ALPACA_SECRET_KEY`
- `ALPACA_BASE_URL` — use `https://paper-api.alpaca.markets` for paper trading.

Never commit API keys or secrets to GitHub.
